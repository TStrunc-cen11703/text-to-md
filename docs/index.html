Převodník dokumentů na Markdown

Vybraný dokument se zpracovává přímo v tomto prohlížeči. Jeho obsah se neodesílá na GitHub ani na jiné servery.

Podporované soubory: Word (.docx), text (.txt) a textové PDF (.pdf). Limit je 20 MB. Při prvním převodu se stáhne převodní prostředí a může to chvíli trvat.
